# Tadika Misali Official Website 🎓

A modern, fully responsive landing page developed for Tadika Misali, featuring localized SEO optimization and automated lead-generation capabilities. 

### 🌐 Live Demo
* **Primary Domain:** [https://tmisali.top](https://tmisali.top)
* **Fallback Domain:** [https://tmisali.netlify.app](https://tmisali.netlify.app)
*(Note: A dual-domain strategy is implemented. If the custom `.top` domain is not renewed in the future, the website remains fully accessible and operational via the Netlify subdomain without any downtime.)*

### 🛠️ Tech Stack & Infrastructure
* **Frontend:** HTML5, CSS3, JavaScript
* **Deployment & Hosting:** Netlify (Continuous Deployment)
* **Backend Services:** Netlify Forms 
* **Security:** Google reCAPTCHA integration

### 🚀 Key Features
* **Responsive Web Design:** Seamless cross-device layout mapping for mobile, tablet, and desktop viewing.
* **Automated Lead Generation:** Contact forms are securely routed to the administration dashboard via Netlify Forms, eliminating the need for a dedicated backend server.
* **Spam Protection:** Integrated reCAPTCHA to filter out automated bot submissions.
* **Localized SEO (GEO):** Optimized metadata and content specifically targeting local searches for "Taman Sri Segambut kindergarten" to capture high-intent local traffic.
